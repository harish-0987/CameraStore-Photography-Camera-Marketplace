2. Project Overview

CameraStore is a modern, responsive photography and camera marketplace web application developed using React.js and JSON Server.

The application provides a complete online shopping experience where users can browse cameras, lenses, lighting equipment, tripods, camera bags, and photography accessories, search and filter products, view detailed specifications, manage their wishlist and shopping cart, authenticate through login and registration, and complete a simulated checkout process.

The project demonstrates a scalable React.js application using component-based architecture, React Router DOM, Redux Toolkit, Axios, REST APIs, and CRUD operations.

The application is designed to simulate a real-world camera marketplace and provides a strong foundation for future integration with a production backend, payment gateway, JWT authentication, and an administrative dashboard.

4. Key Features

User Features

  • User Registration: Create new user accounts with validation.
  • User Login: Authenticate with persistent session storage.
  • Forgot Password: Password reset workflow with simulated OTP verification.
  • Product Browsing: Categorized catalog views for Cameras, Lenses, Lighting, Tripods, Bags, and Accessories.
  • Product Search: Real-time keyword search across names, brands, and categories.
  • Product Filtering: Multi-facet filtering by category, brand, price slider, and camera type.
  • Product Sorting: Sort by Price (Low to High, High to Low), Rating, Discount, and Popularity.
  • Product Details: High-resolution image galleries, technical specifications, and stock indicators.
  • Wishlist Management: Add/remove favorites with instant badge counter updates.
  • Shopping Cart Management: Add items, adjust quantities, remove items, and clear cart.
  • Quantity Management: Real-time item count adjustments with stock limit checks.
  • Coupon Application: Promo code engine (e.g., CAM10, FESTIVE20, PROPHOTO).
  • Checkout: Shipping address entry and simulated payment method selection.
  • Order Placement & Confirmation: Generation of unique order IDs and invoice summaries.
  • User Profile: Personal details, address book, order history, and saved coupons.
  • Order History: Chronological tracking with real-time status updates.
  • Logout: Secure session termination.

Product Features

  • Product Categories: DSLR, Mirrorless, Compact, Action, and Cinema Gear.
  • Product Images: High-resolution photography gear imagery with gallery previews.
  • Product Description: In-depth overviews highlighting sensor features and creative uses.
  • Brand: Filter by industry-standard brands (Sony, Canon, Nikon, Fujifilm, Leica, DJI, etc.).
  • Price & Discount: Live discount tags displaying original price, current price, and percentage saved.
  • Rating & Reviews: Star rating scores and customer review counters.
  • Stock Availability: In-stock status and live quantity tracking.
  • Sensor / Resolution Details: Megapixel count and sensor formats (Full-Frame, APS-C).
  • Lens Mount / Focal Length: Mount compatibility (Sony E, Canon RF, Nikon Z) and focal ranges.
  • Compatibility Information: Lens, battery, and accessory compatibility notes.

7. Project Setup

Step 1 – Create / Clone React Application

npm create vite@latest camerastore
cd camerastore
npm install

Step 2 – Install Required Packages

npm install react-router-dom
npm install axios
npm install bootstrap
npm install react-icons lucide-react
npm install @reduxjs/toolkit react-redux
npm install json-server concurrently

Step 3 – Start the Project

# Start frontend development server
npm run dev

# Start JSON Server mock REST backend
json-server --watch db.json --port 5000

8. Running the Application

Start React Development Server

npm run dev

The Vite development server will provide a local URL such as: http://localhost:5173

Start JSON Server

json-server --watch db.json --port 5000

The mock REST API will be available at: http://localhost:5000 (or http://localhost:3000)

15. Authentication Module

CameraStore provides simulated authentication workflows compatible with JSON Server:

  • Login Fields: Email, Password, Remember Me
  • Registration Fields: Full Name, Email, Mobile Number, Password, Confirm Password
  • Validation: Required checks, email format regex, 10-digit mobile number, and password matching
  • Forgot Password Workflow: Email entry ➔ User verification ➔ OTP token ➔ Password update

Allows users to bookmark cameras and lenses for future purchase:

Manages products selected for purchase with dynamic computations:

  • View cart items with thumbnails, unit prices, and quantities
  • Increase and decrease quantity with stock boundaries

29. Axios Service Layer

API communication is centralized inside src/services/api.js with offline LocalStorage fallback:

import axios from "axios";

const api = axios.create({ baseURL: "http://localhost:5000" });

export const getProducts = () => api.get("/products");
export const getProductById = (id) => api.get(`/products/${id}`);
export const createOrder = (order) => api.post("/orders", order);
export const createProduct = (product) => api.post("/products", product);
